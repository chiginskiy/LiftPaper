# Components

The application uses C# and the system .NET Framework assemblies `mscorlib`, `System`, `System.Core`, `System.Drawing`, and `System.Windows.Forms`. These are operating-system/runtime dependencies and are not redistributed in the executable or release archive. Their respective Microsoft terms apply separately.

No NuGet packages, Python runtime, image model, GIMP code, third-party fonts, icons, sample customer documents, or copied scan images are bundled.

The tonal curve used by the image-processing pipeline is empirical.

Tests generate synthetic images from geometric primitives at runtime. They contain no real signatures or personal information. Source-code licensing is stated in the top-level LICENSE.
