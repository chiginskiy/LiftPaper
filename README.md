# LiftPaper

**Из скана — к чистой печати.**

LiftPaper — локальная утилита для Windows, которая преобразует JPG/PNG-сканы страниц в отдельные PDF A4, подготовленные для печати. Программа осветляет нейтральный фон бумаги, делает нейтральный текст контрастнее, при необходимости сохраняет выраженные цветные штрихи и размещает результат на странице A4, не изменяя исходный файл.

## Идея программы

Скан документа часто выглядит на экране приемлемо, но при печати переносит на бумагу сероватый фон, цветовой шум сканера и слабый контраст текста. LiftPaper решает узкую задачу: **подготавливает уже существующее изображение страницы к повторной печати**.

Программа не заменяет сканер, не распознаёт текст и не пытается восстановить «оригинал» документа. Она обрабатывает пиксели изображения и формирует новый PDF A4, рассчитанный прежде всего на светлую бумагу с тёмным текстом.

Типичный сценарий:

**JPG/PNG скана → LiftPaper → отдельный PDF A4 → проверка → печать в масштабе 100%.**

## Быстрый старт

1. Скачайте `LiftPaper.exe` из раздела **Releases**.
2. Откройте программу.
3. Выберите JPG/PNG или перетащите файлы в окно.
4. Проверьте настройки, особенно ширину очищаемых краёв.
5. После обработки рядом с каждым исходником появится отдельный файл `имя — чистый.pdf`.
6. Просмотрите результат перед отправкой или печатью.
7. Для ожидаемого размера страницы печатайте как A4 в режиме **«Фактический размер / 100%»**.

Исходные JPG/PNG не перезаписываются. Если файл результата уже существует, LiftPaper добавляет номер и сохраняет новый PDF отдельно.

### Перетаскивание на EXE

Если перетащить изображения прямо на `LiftPaper.exe`, обработка начнётся сразу с настройками по умолчанию.

Если нужно изменить ширину очищаемых краёв, защиту цветных штрихов или режим сжатия, сначала откройте программу без файлов, настройте параметры и только затем добавьте сканы.

## Настройки

### Очищаемые края

По умолчанию LiftPaper полностью отбеливает полосу по периметру, соответствующую **8,5 мм на странице A4**.

**Внутри этой полосы из результата удаляется всё без исключения — включая текст, подписи, печати и другие отметки.**

Если полезное содержимое находится близко к краю, установите `0` или меньшее значение до начала обработки.

### Сохранение цветных штрихов

При включённой защите программа старается сохранить выраженные цветные пиксели — например, синие или красные рукописные отметки и печати — за пределами очищаемых краёв.

Это эвристика по цвету, а не распознавание подписей или печатей. Очень бледные, серые или слабо окрашенные штрихи могут измениться. Всегда проверяйте готовый PDF.

### Размер PDF

По умолчанию изображение в PDF хранится без потерь.

Опция **«Компактный PDF»** выполняет однократное JPEG-сжатие с качеством 95. Файл обычно получается меньше, но изображение перестаёт быть строго без потерь.

## Что происходит при обработке

Для каждого входного изображения LiftPaper:

- принимает JPG/JPEG или обычный PNG;
- учитывает EXIF-ориентацию;
- помещает прозрачность PNG на белый фон;
- приводит нейтральные пиксели к нейтральному серому, уменьшая цветовой оттенок бумаги и текста от сканера;
- применяет тоновую кривую: светлый нейтральный фон становится белее, тёмный нейтральный текст — контрастнее;
- при включённой защите не применяет эту нейтральную обработку к выраженным цветным пикселям вне очищаемых краёв;
- полностью отбеливает заданные краевые полосы;
- сохраняет пропорции изображения;
- автоматически выбирает книжную или альбомную ориентацию A4;
- размещает исходные пиксели на странице PDF без дополнительного растрового масштабирования;
- создаёт отдельный PDF рядом с исходником.

## Для чего LiftPaper подходит

Лучший результат ожидается для:

- сканов и фотографий обычных бумажных документов;
- светлой или белой бумаги;
- тёмного текста;
- документов, которые нужно повторно распечатать на A4;
- отдельных цветных подписей, печатей или отметок при включённой защите цвета.

## Ограничения

LiftPaper изменяет изображение документа. Храните исходные файлы.

Версия 0.1.0:

- не выполняет OCR;
- не выравнивает наклон страницы;
- не исправляет перспективу;
- не объединяет несколько изображений в один многостраничный PDF;
- не принимает PDF как входной формат;
- не распознаёт подписи, печати или тип документа;
- не выполняет электронное подписание;
- не определяет фактический размер исходной бумаги.

Изображение любого поддерживаемого размера вписывается в A4. Например, скан A3 также будет размещён на странице A4.

Профиль обработки не предназначен для фотографий, цветных иллюстраций, чертежей и документов, где важны точные серые оттенки или цветопередача.

Максимальный размер входного изображения — **100 млн пикселей**. Очень большие изображения могут потребовать значительного объёма памяти.

## Конфиденциальность

Обработка выполняется локально на компьютере.

LiftPaper не содержит:

- загрузки документов на сервер;
- сетевых запросов;
- телеметрии;
- рекламы;
- автоматического обновления.

Если исходники находятся в папке, синхронизируемой OneDrive, Dropbox или другим облачным клиентом, этот клиент может отправлять файлы в облако независимо от LiftPaper.

Не прикладывайте реальные договоры, подписи, финансовые документы, персональные данные или другие конфиденциальные материалы к публичным GitHub Issues.

## Требования

- Windows 10/11 — целевые версии;
- .NET Framework 4.5 или новее;
- один исполняемый файл `LiftPaper.exe`;
- установка Python, GIMP, дополнительных пакетов, аккаунта или подключения к Интернету не требуется.

Интерфейс версии 0.1.0 — на русском языке.

## Сборка и тесты

В Windows PowerShell из папки проекта:

```powershell
.\build.ps1
.\test.ps1
```

Сборка использует системный компилятор C# из .NET Framework и не загружает пакеты. EXE и контрольная сумма создаются в `dist`. Скрипты не изменяют системную политику выполнения PowerShell.

Пакетная обработка без GUI с настройками по умолчанию:

```powershell
$p = Start-Process .\LiftPaper.exe -ArgumentList '--batch', '"C:\Scans\page 1.png"' -Wait -PassThru
$p.ExitCode
```

Коды завершения:

- `0` — все файлы обработаны;
- `1` — произошла ошибка хотя бы для одного файла;
- `2` — пакетный запуск выполнен без входных файлов.

Ошибка одного файла не останавливает обработку следующих.
