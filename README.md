# LiftPaper

**Чистый фон сканов и PDF A4 — локально, одним EXE для Windows.**

[English](README.en.md) · [Релизы](https://github.com/chiginskiy/LiftPaper/releases)

**Статус лицензии:** все права защищены; открытая лицензия ещё не выбрана. Публичная видимость репозитория сама по себе не разрешает свободное распространение. См. [LICENSE](LICENSE).

LiftPaper подготавливает сканы документов к печати: осветляет фон, усиливает тёмный текст, сохраняет выраженные цветные штрихи и помещает изображение на страницу A4.

## Запуск

1. Скачайте `LiftPaper.exe` из раздела **Releases**.
2. Откройте программу и выберите JPG/PNG либо перетащите файлы на EXE или в окно.
3. Проверьте ширину белых полей. **По умолчанию 8,5 мм: всё внутри этой полосы стирается, включая подписи и текст.** Если отметки расположены близко к краю, выберите `0` или меньшую ширину.
4. Рядом с каждым исходником появится `имя — чистый.pdf`. Повторный запуск создаёт файл с номером, не перезаписывая прежний.
5. Перед отправкой проверьте результат; печатайте на A4 в фактическом размере (100%).

При перетаскивании на EXE обработка начинается с настройками по умолчанию. Чтобы изменить поля до обработки, сначала откройте EXE без файлов.

Для работы нужен только EXE и установленная в Windows среда **.NET Framework 4.5 или новее**. Основная целевая платформа — Windows 10/11. Python, GIMP, аккаунт и подключение к Интернету не нужны. Интерфейс версии 0.1.0 — на русском языке.

## Что программа делает

- Обрабатывает JPG/JPEG и обычные PNG; каждый файл превращается в отдельный PDF.
- Применяет тоновую кривую к нейтральному тексту и фону.
- При включённой защите сохраняет пиксели с выраженными цветными оттенками вне очищаемых полей.
- Полностью отбеливает заданные краевые полосы, сохраняя размеры изображения.
- Учитывает EXIF-поворот; прозрачный фон PNG становится белым.
- Сохраняет пропорции и вписывает изображение в A4; широкие изображения — в альбомный A4.
- По умолчанию использует сжатие PDF без потерь. Опция компактного PDF использует однократное JPEG-сжатие с качеством 95.
- Не изменяет исходники и не создаёт служебные журналы рядом с документами.

## Ограничения

Это обработка изображения, а не распознавание или восстановление документа. Защита цветных штрихов основана на цветовых порогах: она не распознаёт подписи, не гарантирует сохранение очень бледных или серых штрихов и не действует внутри очищаемых полей. Изображение документа неизбежно изменяется; храните исходник.

Профиль рассчитан на светлую бумагу и тёмный текст. Не используйте его без проверки для фотографий, чертежей, цветных бланков и документов с важными серыми оттенками. Размер исходной бумаги не определяется: A3 тоже будет вписан в A4. Нет OCR, выравнивания наклона, объединения страниц, импорта PDF или электронного подписания. Предел входного изображения — 100 млн пикселей; большие изображения требуют значительного объёма памяти.

## Сборка из исходников

В Windows PowerShell из папки проекта:

```powershell
.\build.ps1
.\test.ps1
```

Сборка использует системный компилятор C# из .NET Framework. Загрузка пакетов не требуется. EXE и контрольная сумма появятся в `dist`. Политика запуска PowerShell управляется вашей системой; скрипты не изменяют её.

Пакетная обработка без окна (настройки по умолчанию):

```powershell
$p = Start-Process .\LiftPaper.exe -ArgumentList '--batch', '"C:\Scans\page 1.png"' -Wait -PassThru
$p.ExitCode
```

Коды завершения: `0` — все файлы обработаны, `1` — ошибка хотя бы одного файла, `2` — пакетный запуск без файлов. При ошибке одного входного файла остальные продолжают обрабатываться.
