# LiftPaper 0.1.0 — первый публичный предварительный выпуск

Один EXE для Windows: JPG/PNG → чистый PDF A4, полностью локально.

## Скачать

- `LiftPaper.exe` — программа; отдельная установка не нужна.
- `SHA256SUMS.txt` — контрольная сумма EXE.
- `LICENSE` — условия распространения (также встроены в EXE).
- Исходники и инструкции сборки — в репозитории и архиве исходников соответствующего тега.

## Перед обработкой

**По умолчанию полностью отбеливаются полосы 8,5 мм со всех сторон.** Это удаляет любые отметки в этой зоне. Для документов с содержимым у края откройте EXE без файлов, установите поля `0` или меньшее значение, затем выберите сканы.

Цветные штрихи вне полей защищаются по цветовым порогам. Очень бледные или серые штрихи могут изменяться. Проверьте PDF перед печатью или отправкой. Исходники сохраняются.

Поддерживается .NET Framework 4.5+; целевая платформа Windows 10/11. Интерфейс — русский. Нет OCR, импорта PDF и объединения страниц. Бинарник пока не подписан сертификатом издателя.
