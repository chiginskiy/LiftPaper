# Security and privacy

Treat unknown image files as untrusted input and keep Windows/.NET patched. The program relies on Windows image decoders. It performs no network requests and never intentionally changes source files.

Do not put a real document or executable exploit in a public issue. For a suspected security vulnerability, first open an issue containing only a high-level description and ask the maintainer for a private reporting channel. If GitHub private vulnerability reporting is enabled for this repository, use its **Report a vulnerability** button instead.

Only the latest release is maintained. There is no guaranteed response or remediation deadline. Release binaries are currently unsigned; checksums are integrity checks, not proof of publisher identity.
