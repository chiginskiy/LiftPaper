# Changelog

## 0.1.0 — initial pre-release

- Single executable for Windows; no additional application files or downloaded dependencies.
- JPG/PNG to A4 PDF with lossless compression or optional JPEG quality 95.
- Neutral-background cleanup, text contrast and optional colour-ink protection.
- Configurable full whitening of edge bands; 8.5 mm by default.
- Preserved originals, collision-safe numbered results, batch processing and EXIF orientation.
- Embedded license and project information.
- Public-source build instructions and synthetic regression tests.
